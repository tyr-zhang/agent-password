# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Credential labels are now the primary key: `cred add` overwrites an existing label in place, and `--cred`, `cred show` and `cred rm` accept labels as well as IDs.
- Bilingual operation manuals and an `agent-pwd` AI skill under `skills/agent-pwd/`.
- `samples/` with runnable demos for web login, SSH, SQL, API, env injection, fill, confirmation and ops, each scenario with its own bilingual README, plus a `make samples-check` syntax check.
- Translation-coverage checks that fail when source strings or command-registration prose lack a zh-CN translation.

### Changed

- Credential reference resolution checks labels before IDs, so a label that collides with another credential's ID resolves deterministically to the label.
- `server` port is canonical in `secret.port`; `--port` remains a compatibility alias that overrides it.
- Session idle timeout defaults to 8 hours (hard cap 24 hours), configurable with `AGENT_PWD_*_TIMEOUT` environment variables at daemon startup.

## [1.0.0]

### Added

- Initial implementation of the single-file encrypted vault: Argon2id key derivation, AES-256-GCM body encryption with AAD-bound header, atomic writes and backup rotation, with separate `crypto` and `store` modules.
- Session lifecycle with idle and hard timeouts, lock/unlock/status commands, and automatic clearing of the in-memory DEK.
- Policy engine with ordered `allow` / `confirm` / `deny` rules, default rules written at `init`, and `confirm` for unmatched actions.
- Append-only, hash-chained audit log with `audit tail` and `audit verify`; a failed audit write denies the action.
- Action executors for SSH commands, SQL queries, API calls, environment injection (`env run`) and one-time `fill` handles.
- High-risk action confirmation flow with `confirmation_id` and poll token, Touch ID on macOS, Windows Hello on Windows with master-password fallback, and terminal master-password re-entry on Linux.
- macOS, Windows and Linux support, including per-platform IPC and data directories, service installation, and `doctor` self-checks.
- Human-facing localization for English (`en`) and Simplified Chinese (`zh-CN`) via `--lang` / `AGENT_PWD_LANG`, plus an AI integration contract generated by `agent-pwd docs` from the command registry.
- Machine-readable JSON output by default, documented exit codes (`0/10/20/30/40/1`), and redaction so secrets never appear in CLI output.
